# Trojan Virus Demonstration (Educational Only)

> ⚠️ **IMPORTANT DISCLAIMER**

This repository contains **demonstration code only**. It is created purely for educational and research purposes to help understand how certain types of malware (specifically Trojan-style programs) can work at a conceptual level.

**This code is NOT intended to be used for any malicious, illegal, or harmful purposes. The author takes no responsibility for any misuse of this material.**

## Purpose

This project is a simplified example that shows the basic structure and behavior of a Trojan-style program. It exists to show understanding of:

- How Trojans can disguise themselves
- Common techniques used
- Why security measures are important

Further information is located in the report.
